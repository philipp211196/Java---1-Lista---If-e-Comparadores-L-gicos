# Java — Lista 1: condicionais e comparadores lógicos

> **Categoria:** Estudos de Java · **Status:** exercícios acadêmicos

Exercícios introdutórios de estruturas condicionais (`if`/`else`) e comparações lógicas em Java.

## Conteúdo

- Tema principal: Condicionais e operadores de comparação.
- Soluções distribuídas nos arquivos `.java` na raiz deste repositório.
- Material de estudo e prática; cada arquivo pode ter sua própria classe e método de entrada.

## Como consultar e executar

1. Tenha um JDK instalado e utilize uma IDE Java (por exemplo, IntelliJ IDEA ou VS Code com extensões Java).
2. Abra o arquivo de exercício desejado e confira o nome da classe e as dependências.
3. Execute a classe que possui `public static void main(String[] args)`, se disponível.

> **Observação:** os exercícios foram mantidos em sua estrutura original. Nem todos foram validados para compilação conjunta; execute individualmente conforme necessário.
